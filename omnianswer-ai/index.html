How it works
1. Upload a PDF, Word, Excel, image, or paste text/screenshot.
2. Scriptorium extracts the text and asks the model to separate correct text from genuine corruption.
3. It reconstructs the likely intended text from context — and flags anything it isn't confident about as "Needs Review".
4. You review a side-by-side diff, accept/reject/edit each change, then export.

Privacy

Uploaded files are parsed entirely in your browser. Extracted text (or image data, for screenshots) is sent only to whichever provider you selected above — Groq or Anthropic — using the key you provide, for the sole purpose of analysis. Nothing is uploaded to a Scriptorium server. Projects and history are stored in this browser's local storage on this device only.
