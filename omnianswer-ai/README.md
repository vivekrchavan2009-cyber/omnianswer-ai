# 🧠 OmniAnswer AI

> **Built by Vivek Chavan** | 📞 +91 94048 13521

A multi-LLM AI question solver that sends your question to **10 free AI models simultaneously** and shows all answers side by side.

---

## ✨ Features

- 🤖 10 Free AI Models — Gemini, Llama, DeepSeek, Mixtral, Gemma, Qwen, Mistral, Phi-3 and more
- 📎 Attach images & PDFs — upload your exam paper or textbook photo
- 🕒 Session History — all answers saved, survives page refresh
- 📲 PWA — installable on Android & iOS home screen
- 🔑 Your own API keys — no shared limits, fully independent
- 🌙 Beautiful dark UI

---

## 🚀 Deploy in 5 Minutes

### Step 1 — Upload to GitHub

1. Go to **github.com** → Sign in
2. Click **"New repository"**
3. Name it `omnianswer-ai`
4. Click **"Create repository"**
5. Upload all files from this folder

### Step 2 — Deploy on Vercel (Free)

1. Go to **vercel.com** → Sign in with GitHub
2. Click **"Add New Project"**
3. Select your `omnianswer-ai` repository
4. Click **"Deploy"**
5. ✅ Done! You get a live link like `omnianswer-ai.vercel.app`
